# rosactl Implementation Plan

> **For agentic workers:** Execute task-by-task. Steps use checkbox syntax.

**Goal:** Ship a stdlib-only `bin/rosactl` that orchestrates existing cluster scripts with human status+log UX and `--robot` mode.

**Architecture:** Single Python file wraps `scripts/cluster/*` (and thin extracted helpers for Make-inline bootstrap/ensure-tunnel). Tee logs to `clusters/<name>/logs/`.

**Tech Stack:** Python 3 stdlib (`argparse`, `subprocess`, `unittest`), bash workers.

**Spec:** `docs/superpowers/specs/2026-07-29-rosactl-design.md`

## Global Constraints

- No PyPI deps / no `requirements.txt`
- Single file: `bin/rosactl`
- Do not rewrite Terraform business logic
- On `main`, bootstrap has no dynamic HTPasswd admin yet — steps omit bootstrap-admin until that lands
